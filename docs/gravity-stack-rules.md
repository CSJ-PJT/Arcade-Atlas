# Gravity Stack rules

## 보드와 조각

- 보드는 12×18 사각 격자입니다.
- 조각은 3~4개 셀로 구성된 독자적인 10종 모듈 세트입니다. 작은 2셀과 과도하게 무거운 5셀 조각은 사용하지 않습니다.
- 한 조각의 셀은 서로 다른 에너지와 기호를 가질 수 있습니다.
- seed PRNG가 조각과 에너지를 결정합니다. 게임 규칙에서 `Math.random()`을 사용하지 않습니다.
- 회전은 90도이며, 충돌 시 `0, -1, +1, -2, +2` 순서의 제한적인 수평 보정만 시도합니다.

## 방전

가로 한 줄의 12칸을 모두 채우면 에너지 종류와 관계없이 그 줄이 제거됩니다. 여러 줄이 동시에 완성되면 같은 wave에서 함께 제거됩니다.

완성 줄이 없을 때는 상하좌우로 연결된 같은 에너지 셀 6개 이상이 한 wave에서 동시에 제거됩니다. 대각선은 연결로 인정하지 않습니다. 제거 후 각 열이 독립적으로 아래로 낙하하며, 새로운 완성 줄이나 에너지 그룹이 생기면 다음 wave가 이어집니다.

## 점수

```text
groupScore = groupSize × 10 + max(0, groupSize - 6) × 20
waveScore = sum(groupScore) × waveIndex
```

wave index는 한 조각을 고정한 뒤 1부터 증가합니다. 제거 셀 30개마다 level이 1 증가합니다.

```text
level = 1 + floor(totalClearedCells / 30)
dropInterval = max(300ms, 900ms - (level - 1) × 25ms)
```

속도는 레벨마다 25ms씩 완만하게 빨라지며 300ms 아래로 내려가지 않습니다.

## 멀티플레이 모드

- 일반 모드: 모든 참가자가 같은 seed로 독립 보드를 조작하고 점수와 생존 기록으로 경쟁합니다.
- 아이템 모드: 각 플레이어가 12셀 제거마다 `중력 펄스 → 방어막 → 방해 블록 → 회전 잠금 → 센서 교란 → 속도 증가` 순서로 하나씩 획득합니다. 순서는 방 전체가 아니라 플레이어별로 관리되며 각 아이템은 최대 3개까지 보유합니다.
- 중력 펄스는 현재 조각을 두 칸 강제 낙하시킵니다. 방해 블록은 한 칸의 빈틈을 둔 장애물 줄을 바닥에 추가합니다. 장애물은 같은 에너지 그룹 방전에는 포함되지 않지만 가로 12칸을 완성하면 제거할 수 있습니다.
- 회전 잠금, 센서 교란, 속도 증가는 각각 8초 동안 회전을 막고, 다음 조각을 숨기고, 자동 낙하를 약 1.8배 빠르게 합니다. 같은 효과를 다시 맞으면 강도가 중첩되지 않고 종료 시각만 8초 이상으로 갱신됩니다.
- 방어막은 종류와 관계없이 다음 공격 아이템 한 번을 막고 소비됩니다. 아이템 보유량, 소비, 대상, 차단, 지속시간과 재접속 복구 판정은 멀티플레이 서버가 관리하며 사람과 Atlas AI에 같은 규칙을 적용합니다.

## Atlas AI 플레이어

- 방장은 로비에서 최대 인원 4명 범위 안에서 실제 AI 참가자를 추가하거나 제거할 수 있습니다.
- AI는 사람과 같은 match seed로 독립된 12×18 보드를 생성하고, 조각 회전·가로 위치·연쇄 가능성·높이·구멍을 평가해 매 수를 결정합니다.
- 루키는 상위 후보에서 확률적으로 실수하고, 파일럿은 상위 두 후보를 균형 있게 고르며, 에이스는 현재 최선 후보를 선택합니다. 공정한 조각 seed는 공유하지만 bot slot별 decision seed를 사용해 같은 난이도 AI도 복제되지 않습니다.
- AI 점수, 제거 셀, 레벨, 게임 오버와 아이템 사용은 서버가 계산하고 방의 실시간 순위에 반영합니다.
- 서버 재시작 시 저장된 착수 횟수를 동일 seed로 재생해 AI 보드를 복구합니다.

## 음악

공개 저장소 재배포 권리를 증명하지 못한 사용자 제공 음원은 source와 운영 artifact에서 제외했으며 음악 재생은 비활성화 상태입니다.

## 입력과 상태

- 좌우 방향키: 이동
- 위 방향키: 회전
- 아래 방향키: 한 칸 낙하
- Space: 즉시 낙하
- P/Escape: 일시정지/계속
- R: 일시정지 또는 게임 오버 상태에서 재시작
- 모바일에서는 화면 하단 pointer controls를 사용합니다.

실시간 멀티플레이에서는 개인 일시정지를 제공하지 않습니다. 연결 끊김은 30초 동안 복구하며, 60초 동안 입력이 없으면 기권 처리합니다. 명시적인 `대전 포기`도 제공합니다.

상태는 `ready`, `playing`, `paused`, `gameOver`입니다. background 탭은 자동 일시정지되며 foreground 복귀 시 자동 재개하지 않습니다. 새 조각의 spawn 공간이 없으면 게임 오버입니다.

## 결정성과 독립성

동일 seed, simulation tick, 입력 순서는 같은 조각 sequence와 board를 만듭니다. wall-clock은 판정의 원천이 아닙니다.

Gravity Stack은 기존 상용 낙하 블록 게임의 명칭, 로고, 음악, 공식 조각 세트, 10×20 보드, 줄 제거, 색상 매핑, Hold/ghost/회전 규칙을 사용하지 않습니다. 외부 게임 asset도 포함하지 않습니다.
